## 📖 О проекте

**PureSweep** — мощная утилита очистки Windows уровня CCleaner, только глубже и без заглушек.
Чистит систему, реестр и браузеры, освобождает место и оптимизирует работу ПК.

## ✨ Возможности

**🧽 Очистка**
- Временные файлы (Temp), кэш и логи системы
- Кэш, куки, история и DOM-базы браузеров
- Корзина с затиранием (безвозвратное удаление)
- Дампы памяти (.dmp), кэши Adobe / Steam / Epic / Nvidia / AMD

**🛠️ Система**
- Чистка реестра с созданием точки восстановления
- flushdns + очистка кэша Windows Update
- Удаление старых точек восстановления
- Поиск дубликатов файлов по хешу

**📊 Анализ и инструменты**
- Карта размера папок (как WinDirStat)
- Шредер файлов, поиск пустых папок и битых ярлыков
- Drive Wiper — затирание свободного места (Гутман / DoD 5220.22-M)
- Оптимизация оперативной памяти

**⚡ Health Check** — проверка и очистка системы в один клик

## 🎨 Интерфейс

- Тёмная тема и аккуратный дизайн
- Раздел настроек: смена языка и темы
- Только для **Windows 10 / 11**

## 📦 Установка

1. Скачай `PureSweep.exe` из раздела [**Releases**](https://github.com/sxrozs/PureSweep/releases/latest)
2. Запусти — установка не требуется (portable)

> ⚠️ Утилита работает с системными файлами и реестром — антивирус может реагировать ложным срабатыванием. Точка восстановления перед чисткой реестра создаётся автоматически.

## 🛠️ Сборка из исходников

Требуется **Qt 6** и компилятор C++ (MSVC / MinGW).

```bash
git clone https://github.com/sxrozs/PureSweep.git
cd PureSweep
qmake
make
```

Или открой проект в **Qt Creator** и нажми **Build**.
